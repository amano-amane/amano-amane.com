# 機能要件

## ページ構成

**1ページ構成（シングルページ）** - セクション分けでコンテンツを整理

```
/
├── #hero     ... ファーストビュー
├── #about    ... 自己紹介
├── #works    ... 作品一覧
├── #skills   ... 技術スタック
├── #links    ... 外部リンク
└── #contact  ... 連絡先
```

---

## セクション詳細

### 1. Hero（ファーストビュー）

| 項目 | 内容 |
|------|------|
| アンカー | `#hero` |
| 目的 | 第一印象、サイトの顔 |

#### 要素
- キャッチコピー
- メインビジュアル（イラスト/アバター）
- 簡単な肩書き（インディーゲームクリエイター）
- スクロール誘導

---

### 2. About（自己紹介）

| 項目 | 内容 |
|------|------|
| アンカー | `#about` |
| 目的 | 天野あまねについて知ってもらう |

#### 要素
- プロフィール画像
- 自己紹介文（2〜3段落）
- 目指していること・ビジョン

---

### 3. Works（作品一覧）

| 項目 | 内容 |
|------|------|
| アンカー | `#works` |
| 目的 | 作品を見せる |

#### 要素
- 作品カード（グリッド表示）
  - サムネイル画像
  - タイトル
  - カテゴリタグ（ゲーム/イラスト）
  - 簡単な説明
  - 外部リンクボタン（GitHub等）

---

### 4. Skills（技術スタック）

| 項目 | 内容 |
|------|------|
| アンカー | `#skills` |
| 目的 | 使える技術を一覧表示 |

#### 要素
- スキルカテゴリ別表示
  - ゲームエンジン（Godot等）
  - プログラミング言語
  - ツール
  - その他（イラスト等）
- アイコン + スキル名

---

### 5. Links（外部リンク）

| 項目 | 内容 |
|------|------|
| アンカー | `#links` |
| 目的 | 各種SNS・外部サービスへの導線 |

#### 要素
- リンクボタン/カード
  - Twitter/X（メイン）
  - GitHub（ポートフォリオ公開後に追加予定）

※ 現時点ではTwitter/Xのみ

---

### 6. Contact（連絡先）

| 項目 | 内容 |
|------|------|
| アンカー | `#contact` |
| 目的 | 連絡手段を提供 |

#### 要素
- メールリンク（`mailto:`）
- 注意書き（返信に時間がかかる等）

---

## 共通要素

### ヘッダー（固定）
- ロゴ/サイト名
- ナビゲーション（各セクションへのアンカーリンク）
- ハンバーガーメニュー（モバイル）

### フッター
- コピーライト
- SNSアイコンリンク

---

## 追加機能

### OGP/SNS共有
- OGPタグ設定
- Twitter Card対応
- シェア用OGP画像

### アクセス解析
- Google Analytics 4

### SEO
- 適切なmeta title / description
- favicon
- sitemap.xml
- robots.txt
