## モチーフ・装飾

### 丸ドット

- 背景パターンとして使用
- 散りばめる感じ
- サイズはランダム or グラデーション

### 斜めライン

- セクション区切りに斜めのライン
- ダイナミックな印象
- 角度: 約5〜10度

### サイバー要素

- グリッド線（薄く）
- スキャンライン風エフェクト（控えめ）
- ホバー時のグリッチ風アニメ（任意）

## レイアウト

### 基本構成

```
┌────────────────────────────────────┐
│          Header（固定）            │
├────────────────────────────────────┤
│                                    │
│           Hero Section             │
│         （斜めカット下部）          │
│                                    │
├────────────────────────────────────┤
│           About Section            │
├────────────────────────────────────┤
│           Works Section            │
│         （カードグリッド）          │
├────────────────────────────────────┤
│          Skills Section            │
├────────────────────────────────────┤
│           Links Section            │
├────────────────────────────────────┤
│          Contact Section           │
├────────────────────────────────────┤
│              Footer                │
└────────────────────────────────────┘
```

### セクション区切り

- 斜めのクリップパス or SVG
- 色の切り替えで区別

---

## コンポーネントスタイル

### ボタン

- 角丸（8px〜16px）
- ホバーでスケールアップ or グロー
- ビビッドカラー

### カード

- 角丸
- シャドウ（サイバー風：ピンク or シアンのグロー）
- ホバーで浮き上がる

### ナビゲーション

- 透過背景 + blur
- スクロールで背景色追加
- アクティブ状態はアンダーライン or 色変更
