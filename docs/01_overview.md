# プロジェクト概要

## 基本情報

| 項目 | 内容 |
|------|------|
| プロジェクト名 | 天野あまね ポートフォリオサイト |
| ドメイン | amano-amane.com |
| 運営者 | 天野あまね（あまのあまね） |
| 肩書き | インディーゲームクリエイター志望 |
| 活動内容 | ゲーム開発 / イラスト |
| 運営形態 | **匿名**（本名・所属は非公開） |

## 目的

- **名刺代わり**のポートフォリオサイトとして機能
- 作品（ゲーム、イラスト等）を一覧で見せる
- SNS・GitHub等への導線を設ける
- 将来的にゲーム内ランキング機能等のAPI連携を想定

## ターゲットユーザー

1. **ゲーム業界関係者**：採用担当、ディレクター等
2. **同人・インディー界隈の仲間**：コラボや交流のきっかけ
3. **一般ユーザー**：作品に興味を持った人

## サイトの方針

### 運用方針
- 更新頻度は低くてもOKな設計
- 一人で保守できるシンプルな構成
- 複雑なCMSは使用しない（コード直接編集でOK）

### デザイン方針

**コンセプト**: Kawaii Pop × Cyber

制作中ゲームの世界観を反映

| 要素 | 内容 |
|------|------|
| テイスト | ポップ × サイバー × 遊び心 |
| カラー | ビビッドカラー（ピンク × ネイビー基調） |
| モチーフ | 丸ドット、斜めライン、デジタル感 |
| 雰囲気 | 明るく楽しい、でもどこかサイバーな深み |

#### キーワード
- Kawaiiポップ
- ビビッドカラー
- 丸ドット
- 斜め（ダイナミック）
- デジタル / サイバー
- 遊び心

#### レスポンシブ
- PC / タブレット / スマホ対応

### 言語
- 日本語のみ（多言語対応なし）

## スコープ外（やらないこと）

- ブログ機能
- コメント機能
- 複雑なCMS
- 多言語対応
- リアルタイムチャット
